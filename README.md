# Õppeainete tagasiside

Veebirakendus õppeainete tagasiside kogumiseks.

## Nõuded
- Git
- Docker Desktop

## Käivitamine
Ava projekti kaust terminalis ja käivita:

```bash
docker compose up -d
```

Ava brauseris: http://localhost:8080

## Peatamine
```bash
docker compose down
```

## Projekti struktuur
- frontend/index.html — lehe struktuur
- frontend/style.css — lehe kujundus
- frontend/script.js — lehe käitumine
- compose.yaml — Dockeri seadistus
